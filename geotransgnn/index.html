Data-safe interactive mode

The public repository intentionally does not redistribute the restricted raw Hatu geochemical dataset. This viewer therefore opens in a clearly labelled demo mode. If you have the authorized workflow output, load hatu_geotransgnn_results.csv; parsing and visualization occur locally in the browser and the file is not uploaded by this page.

Expected fields include xyAuanomaly_score_geotransgnnpredicted_au_geotransgnn.

GeoTransGNN 3D Explorer · research visualization companion. The 3D representation is an analytical visualization of spatial coordinates plus a selected model/geochemical variable and should not be interpreted as a geological 3D subsurface model.
