Data-safe behavior

The raw Hatu file is not embedded in this public page. When loaded manually, the browser reads the original GBK encoding, parses the combined x y field, removes the one unusable x/y/Au record, and applies the paper-aligned Au > 300 screen (6 records) for a final 10,939-record raw-data view.

Raw mode visualizes measured geochemistry only. GeoTransGNN anomaly score and predicted Au are shown only when the model result CSV actually contains those columns.

The 3D Z dimension is an analytical variable selected by the user, not topographic elevation or a subsurface geological depth. Displayed edges are visualization-neighbour links for the rendered subset; the published model graph uses the full spatial KNN graph with k=13.
